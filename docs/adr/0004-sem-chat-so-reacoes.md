# Sem chat, só reações

A sala não tem chat. No lugar, há um conjunto fixo e pequeno de reações (umas quatro, uma tecla cada) aos eventos da sala, permitidas até durante o foco; quem recebe vê só um contador no próprio card. Chat de texto livre empurra o app para virar rede social, exige moderação e cria expectativas (histórico, menções, notificações) que competem com o foco. Reação diz "te vi" sem abrir conversa. Para conversar, o grupo já tem WhatsApp ou Discord.
